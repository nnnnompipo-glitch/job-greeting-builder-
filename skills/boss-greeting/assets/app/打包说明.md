# BOSS 招呼语助手 · 多模型便携版

这是 Windows 64 位便携包，带 Node.js 运行环境。完整解压后即可启动；使用豆包或本地模型时无需安装 Codex。浏览器采用 Chrome 或 Edge。

## 开始使用

1. 把 ZIP 完整解压到固定文件夹。不要在压缩包里直接运行，也不要把解压目录和原有助手同时启动。
2. 双击 `启动助手.cmd`，看到 `Helper is running` 后保持服务运行。运行环境位于 `runtime/node.exe`，无需另外安装 Node.js。
3. 在 Chrome 地址栏打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压目录里的 `extension` 文件夹。Edge 使用 `edge://extensions`。
4. 点击工具栏里的“BOSS 招呼语助手”。打开本目录 `private/pairing.txt`，复制整行配对码并填入扩展，保存。
5. 在扩展中打开“模型与个人资料设置”，选择模型服务，填写模型名称和所需密钥，再测试连接、保存设置。
6. 填写自己的专业、经历、项目和求职地区。空白模板首行有 `PROFILE_NOT_CONFIGURED` 标记，填写真实资料后删除这一行再保存。可参考 `templates/profile.example.md`，也可把原来助手里的 `private/profile.md` 内容复制过来。
7. 开启前台岗位检测，刷新 BOSS 岗位详情页。生成后可核对、修改、复制，并自行发送。

“测试连接”仅使用简短测试文字；实际生成会使用岗位正文和你保存的个人资料。发送消息仍由你手动完成。

## 接入不同模型

| 类型 | 默认 Base URL | 还需要填写 |
| --- | --- | --- |
| 豆包 / 火山方舟 | `https://ark.cn-beijing.volces.com/api/v3` | 方舟 API Key，以及控制台中可调用的模型 ID 或推理接入点 ID |
| Ollama | `http://127.0.0.1:11434/v1` | 已安装的模型名称；需提前启动 Ollama 服务并准备好模型 |
| LM Studio | `http://127.0.0.1:1234/v1` | 已加载的模型名称；需在 LM Studio 中启动本地服务 |
| 其他兼容接口 | 服务商提供的 OpenAI 兼容 Base URL | 模型名称，以及服务商要求的 API Key |
| Codex | 使用本机 Codex 登录 | 另行安装并登录 Codex；便携包未包含 Codex 程序 |

豆包桌面版或网页版的登录不等于方舟 API Key。模型 ID 以你的控制台为准。不要在 Base URL 后重复添加 `/chat/completions`。

接口配置参考：[火山方舟兼容接口](https://console.volcengine.com/ark/region%3Acn-beijing/docs/compatible-with-openai-sdk)、[Ollama 兼容接口](https://docs.ollama.com/api/openai-compatibility)、[LM Studio Chat Completions](https://lmstudio.ai/docs/developer/openai-compat/chat-completions)。

本地模型在本机地址运行时，模型推理输入发送给本机服务。选择云端接口时，岗位和个人资料将发送到你选定的服务商，并使用该服务商的额度。助手不会在本地模型失败时自动切换到云端。

接口支持程度因模型及服务端版本而异。若连接正常但返回格式不兼容，可在高级设置中选择其他 JSON 输出方式；生成失败后请检查提示再手动重试。

## 资料与移交

通用 ZIP 不包含开发者或此前用户的简历、作品集、个人资料、API Key、Codex 登录、配对码或运行日志。首次启动在解压目录生成独立的 `private/`。

日常使用后，`private/` 会保存你填写的资料、密钥和本机配对码。API Key 保存在本机配置中，浏览器页面不显示已保存的密钥。将程序转交他人时，请使用原始通用 ZIP；不要把使用后的整个文件夹直接发出去。

停止服务请双击 `停止助手.cmd`。没有设置开机自动启动。安装的模型文件和本地模型软件由你自行管理，本包不附带或自动下载模型权重。

## 常见问题

- **一直显示暂停**：点击页面浮窗的“开启检测”，或在扩展弹窗中开启自动检测。
- **连接不到助手**：先运行 `启动助手.cmd`，确认另一份助手没有占用本机端口 `43127`。
- **本地模型连接失败**：确认本地服务已启动，地址、端口、模型名与服务端一致。
- **豆包鉴权或模型不存在**：检查方舟 API Key、已开通模型和调用标识；不需要重新登录豆包聊天网页。
- **更换了解压目录**：在扩展管理页移除旧目录中的扩展，再加载新目录的 `extension`。
