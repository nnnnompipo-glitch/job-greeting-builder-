# 求职招呼语助手 · 1.3.2 Windows 便携版

本包随附 `CHANGELOG.md`，记录各版本新增和修复。开发发布使用 `scripts/release.ps1`，会将源码、构建包及校验文件保存在独立的版本归档中；流程见仓库 `RELEASING.md`。

完整解压后使用 Chrome 或 Edge。便携包包含 Node.js 运行环境；生成统一需要本机另行安装 Codex CLI，并使用自己的 ChatGPT 账号登录。无需填写模型地址、模型 ID 或 API Key。

## 首次使用

1. 将 ZIP 完整解压到固定目录，不在压缩包内运行，不与其他目录的助手同时启动。
2. 检测已有 Codex。已安装的 Codex 桌面应用可能自带可用命令行；缺少时按 [官方安装说明](https://learn.chatgpt.com/docs/codex/cli) 安装。具备 npm 可运行 `npm install -g @openai/codex@latest`；没有 npm 则用 [官方 Windows 独立安装器](https://learn.chatgpt.com/docs/enterprise/windows-deployment)。
3. 在终端运行 `codex login`，用自己的 ChatGPT 账号完成浏览器登录，再运行 `codex login status` 确认使用 ChatGPT。账号权限与额度以实际状态为准。[官方认证说明](https://learn.chatgpt.com/docs/auth)
4. 双击 `启动助手.cmd` 启动本机服务。在 `chrome://extensions` 或 `edge://extensions` 正常加载本目录的 `extension`。
5. 从本机 `private/pairing.txt` 复制配对码并填入扩展。打开设置检查 Codex 登录，填写自己的专业、经历、项目与求职地区。模板首行标记在填写真实内容后删除，也可参考 `templates/profile.example.md`。
6. 可导入 PDF、PNG/JPG/JPEG/BMP、UTF-8 TXT/MD。Windows 本机识字后先预览、编辑，再确认加入并保存。每个文件最多 25 MiB，PDF 最多识别前 40 页；中文或英文 OCR 组件须由 Windows 提供。
7. 选择严肃专业、亲和活泼、热情夸张或灵动巧思。开启前台岗位检测，刷新 BOSS直聘、猎聘或智联招聘的网页岗位详情，核对草稿后自行复制、发送。

豆包等有本地工具的 AI 可以协助完成上述安装，但其聊天登录不会成为生成凭证。只有文字聊天能力的客户端只能提供指导。登录检查通过后，还需实际岗位生成验证；不会替用户向招聘者发送信息。

## 升级与私有资料

升级到 1.3.0 时，旧版其他模型配置先备份到本机 private 后迁移为 Codex。个人资料、配对和语气继续保留；不再调用旧模型接口，不读或复制 Codex 认证文件。升级扩展后，在扩展管理页重新加载，再刷新岗位页。

通用 ZIP 不包含简历、作品集、用户资料、账号凭证、配对码或运行日志。使用后 private 会包含自己的资料和配对信息；交给其他人时请提供通用 ZIP，不发送使用后的整个文件夹。Codex 运行时会使用自己的账号额度；其可用权限和网络状况决定能否生成。

## 常见问题

- 找不到 Codex：完成官方安装并打开新终端，或让安装 AI 重新运行检测。
- Codex 未登录：运行 `codex login`，再确认 `codex login status` 显示 ChatGPT 登录。
- Codex 使用 API Key：在 Codex 中切换为自己的 ChatGPT 账号；不要把密钥填入助手。
- 一直暂停：在浮窗点击“开启检测”，或在扩展弹窗启用前台检测。
- 连接不到助手：启动本目录程序，检查是否有另一份助手占用端口 43127。
- 岗位无法识别：正常登录招聘平台并展开正文后重试；平台改版可能需要更新助手。

双击 `停止助手.cmd` 停止服务。本包未设置开机自启，也不包含 Codex 程序或账号。Node.js 许可随包位于 `runtime/LICENSE.txt`。
